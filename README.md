# 💳 C++ ATM System

## 📌 Overview
This is a simple **ATM System project** developed in C++. It simulates real-world banking operations using a console-based menu system. The project is designed to practice fundamental programming concepts and improve problem-solving skills.

---

## 🚀 Features
- Check account balance  
- Deposit money  
- Withdraw money  
- Exit system safely  
- Simple menu-driven interface  

---

## 🧠 Concepts Used
- Variables and data types  
- Conditional statements (if-else / switch)  
- Loops (while / do-while)  
- Basic input/output handling  
- Logic building for real-world simulation  

---

## 💻 How It Works
1. The program starts and displays a menu  
2. User selects an option:
   - Check Balance
   - Deposit Money
   - Withdraw Money
   - Exit  
3. The system performs the selected operation  
4. Process repeats until the user exits
